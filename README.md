# AI Usage Bar

Windows 작업표시줄 맨 왼쪽에 **Claude · Codex · Grok · Cursor 잔여 사용량**과 **이 PC의 CPU·메모리·온도**를 macOS 메뉴 막대처럼 깔끔하게 상시 표시합니다. 마우스를 올리면 제어 센터 스타일의 반투명(Acrylic) 상세 카드가 열립니다.

```
● Claude  ━━━━━━━──  66% 20:09  │  ● Codex  ━━━━━━━━━─  88% 10/7  │  ● Grok  ━━━━━━━━━─  94% 10/7
          ━━━━━━━━━─  85% 01:59
```

## 요구 사항

- Windows 10 / 11 (별도 런타임 설치 불필요, .NET Framework 4.8 내장)
- 표시할 서비스의 CLI가 이 PC에 로그인되어 있어야 합니다.
  - Claude: [Claude Code](https://claude.com/claude-code) 로그인 (`%USERPROFILE%\.claude\.credentials.json`)
  - Codex: Codex CLI 로그인 (`%USERPROFILE%\.codex\auth.json`)
  - Grok: Grok CLI 사용 기록 (`%USERPROFILE%\.grok\sessions`)
  - Cursor: Cursor 앱 로그인 (`%APPDATA%\Cursor\User\globalStorage\state.vscdb`, Windows 기본 SQLite로 읽기만 함)
- 로그인되지 않은 서비스는 `--`로 표시되고, 나머지는 정상 동작합니다.

## 설치 / 제거

1. `AIUsageBar-Setup.exe` 실행 (관리자 권한 불필요, 사용자 폴더에 설치)
2. 서명되지 않은 프로그램이라 SmartScreen 경고가 뜰 수 있습니다: **추가 정보 → 실행**
3. 제거: Windows 설정 → 앱 → AI Usage Bar → 제거

## 읽는 법

| 표시 | 의미 |
|---|---|
| 고리 색 | 서비스: Claude 주황 · Codex 초록 · Grok 검정(다크 모드 흰색) · Cursor 보라, 파란 `CPU`·`RAM`은 이 PC |
| 고리 | 가장 빠듯한 한도의 **남은** 양 |
| `89 · 30` | 한도별 **남은** % (Claude는 5시간 · 주간, Codex·Grok은 주간) |
| `20:09` / `10/7` | 리셋 시각 (24시간 이내면 시:분, 아니면 월/일) |
| 주황색 숫자 | 남은 양 20% 이하 |
| 빨간색(고리 깜빡임) | 남은 양 5% 미만 |
| 흐린 색 | 10분 넘게 갱신 실패 (마지막 값 표시 중) |
| `로그인 필요` | CLI에서 다시 로그인 필요 |

- **마우스를 올리면** 상세 카드: 요금제, 서비스별 남은 %와 막대, 초기화 날짜·시각과 남은 시간, Codex 크레딧, Grok API 환산 금액·오늘 토큰
- 작업표시줄에 공간이 모자라면 글자 크기를 먼저 지킵니다: 서비스 이름을 숨기고(색 고리만) → 리셋 시각을 숨기고 → 그래도 모자랄 때만 100%까지 25%씩 줄입니다. 상세 카드에는 항상 모두 표시됩니다
- 상세 카드와 바탕화면 카드는 Windows 11에서 진짜 흐림(Acrylic) 배경을 씁니다. 지원하지 않는 Windows에서는 같은 모양의 불투명 카드로 표시됩니다
- **왼쪽 클릭**: 상세 패널 고정 / 해제
- **오른쪽 클릭**: 지금 새로고침 · 설정 · Windows 시작 시 실행 · 종료

## 바탕화면 카드 (위젯)

- 상세 카드를 바탕화면에 계속 띄워 둘 수 있습니다: 작업표시줄 바 우클릭 → **바탕화면에 카드 띄우기**, 또는 설정 → "상세 카드를 바탕화면에 띄워두기".
- 마우스로 끌어 옮기면 위치를 기억합니다. 화면 밖이 되면 주 모니터 오른쪽 아래로 돌아옵니다.
- 크기: 카드 우클릭 → **크기**(50 ~ 150%), 카드 위에서 **Ctrl + 마우스 휠**(10%씩), 또는 설정 → "바탕화면 카드 크기".
- 카드 우클릭 메뉴: 항상 위에 표시 / 크기 / 카드 숨기기 / 설정. 기본은 다른 창 아래에 깔리는 위젯입니다.

## PC 상태

- `PC` 블록: CPU 점유율과 메모리 사용률(사용 중 %), 2초마다 갱신. 80% 이상 노랑, 95% 이상 빨강
- 온도: NVIDIA GPU 온도는 드라이버의 NVML로 읽습니다(`GPU 46°`). CPU 온도는 Windows가 열 센서(ACPI)를 제공하는 PC(주로 노트북)에서만 표시됩니다. 데스크톱 CPU 온도는 관리자 권한 드라이버가 필요해 지원하지 않습니다.

## Cursor 표시에 대해

- Cursor 설정 → 사용량과 같은 값입니다. 위 막대 = 포함 사용량 전체, 아래 막대 = API 사용량, 리셋 = 청구 주기 종료일
- 로그인 토큰은 읽기만 하며 cursor.com에만 보냅니다.

## Grok 표시에 대해

- 게이지: **SuperGrok 구독 한도 대비 잔여 %**와 리셋 시각입니다. grok.com → 설정 → 사용량의 "매주 SuperGrok 한도"와 같은 값입니다.
- 이 값은 Grok CLI(`grok agent stdio`)를 하나 상주시켜 갱신 주기마다 조회합니다(약 40MB, 조회당 약 0.2초). Grok 사용 기록이 바뀌면 최대 30초에 한 번 추가로 조회합니다. 앱을 끄면 함께 종료됩니다.
- grok.com 채팅의 "주간 Grok Bot 제한"은 CLI가 제공하지 않아 표시하지 않습니다.
- 상세 카드의 `API 환산 (이번 주)`는 이번 주 사용량을 API 요금으로 환산한 참고 금액입니다. 실제 청구 금액이 아닙니다.
- 구독 한도를 읽을 수 없는 환경(API 키 사용 등)에서는 **설정 → Grok 주간 예산($)** 대비 잔여 %로 대신 표시합니다. 0이면 금액만 표시합니다.

## 설정

오른쪽 클릭 → 설정. `%APPDATA%\AIUsageBar\settings.json`에 저장됩니다.

| 항목 | 기본값 |
|---|---|
| 갱신 주기(초) | 120 (최소 60) |
| Grok 주간 예산($) | 0 (구독 한도를 못 읽을 때만 사용) |
| 표시할 서비스 (Claude·Codex·Grok·Cursor·PC 상태) | 모두 |
| 작업표시줄에 리셋 시각 표시 | 켜짐 |
| Windows 시작 시 실행 | 설치 시 선택 (작업 스케줄러의 로그온 작업 `AIUsageBar`로 등록해 로그인 직후 바로 시작) |

## 위치와 겹침

- Windows 11 가운데 정렬: 작업표시줄 맨 왼쪽(위젯 자리). **위젯(날씨)이 켜져 있으면 겹치니** 작업표시줄 설정에서 위젯을 꺼 주세요.
- Windows 11 왼쪽 정렬: 시작 버튼을 가리지 않도록 알림 영역(시계) 왼쪽에 표시합니다.
- Windows 10: 작업 표시 영역을 오른쪽으로 밀어 공간을 확보합니다. 종료하면 원래대로 돌아갑니다.
- 탐색기가 다시 시작되면 2초 안에 자동으로 다시 붙습니다.

## 개인정보

- 각 CLI가 저장한 로그인 정보를 **읽기만** 합니다. 토큰을 갱신하거나 수정하지 않습니다.
- 사용량 조회는 각 서비스의 공식 주소로만 보냅니다: `api.anthropic.com`, `chatgpt.com`, `cursor.com`. Grok은 로컬 파일과 로컬 Grok CLI만 사용합니다(CLI가 자체 로그인으로 xAI에 조회).
- 오류 기록: `%APPDATA%\AIUsageBar\error.log`

## 빌드

```powershell
winget install JRSoftware.InnoSetup   # 처음 한 번
pwsh ./build.ps1                      # 테스트 → 빌드 → dist\AIUsageBar-Setup.exe
```

필요: .NET SDK 8 이상 (net48 대상 빌드), Inno Setup 6.
